rsync是一款非常快速且功能极其丰富的文件复制和同步工具，最著名的特性是增量传输算法，在同步文件时只传输源文件和目标文件之间的差异部分，而不是整个文件。

## ssh和rsync
ssh是"路",rsync是"车"。

ssh (Secure Shell)：是一个安全网络协议，处于传输层。它主要负责建立一条加密的、安全的通信通道。它本身不关心你传输什么数据，只保证数据在传输过程中不被窃听或篡改。

rsync：是一个文件同步工具，处于应用层。它负责“决定传什么”和“怎么传更高效”（比如只传差异部分）。

rsync 可以使用 ssh 作为它的底层传输通道。当你在命令中加上 -e ssh 时，rsync 就会把数据“装进” ssh 建立的安全隧道里进行传输。

## rsync和sshfs

rsync是一个一次性或周期性命令，它会对比源和目的地的差异，计算出需要传输的数据块，然后将差异数据复制进去。任务结束进程也结束了。

sshfs是一个持续进程，基于ssh协议，将远程服务器的目录"挂载"到本地一个空文件夹上，只要保持挂载，它就会一直运行。

## 使用方式
rsync的命令行语法和scp类似：

```shell
rsync [] source_path dest_path
```

将目录/source/的内容同步到/dest,并保留所有属性、显示进度：
```shell
rsync -avh --progress /source/ /dest/
```
注意源路径末尾的`/`有特殊含义，带`/`表示同步目录内容，不带则表示同步目录本身。

远程同步，将本地的 example.txt 同步到远程服务器 user 的家目录下，使用压缩传输：
```shell
rsync -avz example.txt user@remote_host:/home/user/
```
